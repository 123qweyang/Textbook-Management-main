# 导入"网络异常"诊断方案

## 问题分析

"新增"是普通 POST JSON 请求，"导入"是 **multipart/form-data 文件上传**。两者走同样的 `/jeecgboot/` location 代理，但文件上传对 nginx 有特殊要求。

## 诊断步骤（在服务器 SSH 依次执行）

### 步骤1：打开浏览器 F12，复现导入

看看 Network 面板中上传请求的状态码是什么：
- 如果是 **413** → 文件超过 nginx 大小限制（默认 1MB）
- 如果是 **(failed)** 或 **(canceled)** → 请求超时或连接断开

### 步骤2：检查上传目录

```bash
# 生产配置的上传路径
ls -la /data/project/upload/
```

### 步骤3：确认后端日志中有没有错误

```bash
tail -50 /www/wwwroot/backend/logs/spring.log | grep -i "error\|upload\|import"
```

## 根据结果修复

### 情况A：413 或超时 → 改 nginx 配置

在 `location /jeecgboot/` 块中加两行：

```nginx
location  /jeecgboot/ {
    proxy_pass         http://127.0.0.1:8080/jeecg-boot/;
    proxy_redirect off;
    
    # ===== 加这两行 =====
    client_max_body_size 50m;          # 允许上传最大50MB
    proxy_read_timeout 300s;           # 导入处理超时5分钟
    
    proxy_set_header  Host             $host;
    # ... 其余不变
}
```

改完：`nginx -t && nginx -s reload`

### 情况B：上传目录不存在 → 创建并授权

```bash
mkdir -p /data/project/upload
chown -R www:www /data/project/upload
chmod -R 755 /data/project/upload
```

### 情况C：后端报错 → 查看具体异常

> 把步骤3的日志输出发给我，直接定位。
