## 硬件配置

| 组件 | 规格 |
|------|------|
| CPU | Intel Core i7-14650HX（8P + 8E，共 16 核 24 线程） |
| GPU | NVIDIA GeForce RTX 5060 Laptop GPU (8 GB) |
| 内存 | 16 GB DDR5 5600 MHz × 2（共 32 GB） |
| 存储 | 1 TB PCIe 4.0 + 1 TB PCIe 3.0 |
| 操作系统 | Windows 11 Pro for Workstations |

**Why:** 开发环境运行在这台本地机器上，配置信息用于评估资源可用性和性能调优。

**How to apply:** 运行构建、启动服务、批量处理时参考此配置以评估瓶颈。
